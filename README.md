# 🌱 Self-Management System (RPG 版自我管理系统)

这是一个将“个人管理”游戏化的全栈 Web 应用。通过将任务管理、奖励机制与 RPG 属性树相结合，提升个人成就感。

## 🌟 核心创意
*   **智能待办 (Smart Todo)**：支持优先级设置，系统根据任务紧迫程度自动进行动态排序。
*   **属性成长系统 (RPG Attribute)**：每个任务关联特定能力（如：编程任务提高“智力”，运动任务提高“体质”），完成任务获取经验值并升级。
*   **幸运大转盘 (Reward Turntable)**：完成规定数量的任务可获得“抽奖机会”，奖励可自定义（如：喝杯奶茶、奖励一小时游戏），增加趣味性。
*   **本地数据持久化**：目前所有数据存储在项目根目录的 `./data` 文件夹下，方便个人备份与迁移。

## 🛠️ 技术栈 (Technology Stack)

*   **前端**: Vue 3 (CDN 引入，无需构建)
*   **后端**: Express (Node.js 本地服务器)
*   **数据存储**: 本地 JSON 文件 (`./data/db.json`)
*   **架构理念**: 前后端分离设计，API 层与 UI 解耦
