# 🌱 Self-Management System (RPG 版自我管理系统)

这是一个将"个人管理"游戏化的全栈 Web 应用。通过将任务管理、奖励机制与 RPG 属性树相结合，提升个人成就感。

## 🌟 核心创意

- **智能待办 (Smart Todo)**：
  - **四大分类模块**：日常任务、紧急不重要/无成长：抽空做、近期DDL、长期任务/目标/想发展的点，各模块有独立底色
  - **模块可折叠**，点击头部展开/收起
  - **拖拽排序**：HTML5 拖拽，自由调整任务顺序和跨模块移动，支持拖入空模块
  - **子任务拆分**：单击任务打开 Modal，飞书风格「＋」行快速添加，支持内联编辑
  - **截止日期**：DDL 任务内联日期选择器，自动计算并显示「剩X天/已逾期X天/今天截止」
  - **撤销/重做**：Ctrl+Z 撤销、Ctrl+Y 重做，支持所有操作（含打勾），工具栏按钮可视化操作
  - **进度条**：右上角炫酷动画进度条（仅统计日常任务 + 紧急不重要）
  - **恐吓DDL**：每天随机选取一个近期 DDL 在顶部横幅展示，完成可得 **3 次抽奖**奖励
  - 优先级 0-10（含小数），按优先级降序排列，优先级相同时按截止日期升序
  - **按日期分文件存储**，每天独立管理
  - **日常任务模板**，设置后每天自动导入，且自动从昨天继承（✓ 状态清零）
  - **日期选择器**，可查看任意日期的待办（历史日期只读）
  - **一键继承**，将上一天未完成的待办加入今天
  - **打勾划线保留**，完成的任务保留可见

- **RPG 属性成长 (RPG Attributes)**：完成待办赚取经验值 → 升级 → 获得属性点 → 加点（力量/智力/耐力/精神）
- **幸运大转盘 (Reward Turntable)**：完成待办获得抽奖次数，转盘赢取 XP 或属性点奖励
- **首页语录 (Hero Quotes)**：全屏英雄区展示 3 条随机励志语录，可自定义语录库
- **数据统计 (Data Stats)**：近 7 天待办完成趋势、XP 趋势图、分类统计
- **模块化 JSON 持久化**：数据按模块分目录存储，换设备拷贝 `data/` 即可迁移

### 📂 数据目录结构

```text
data/
├── global.json           # RPG + 转盘全局数据（等级、属性、抽奖次数等）
├── dailies.json          # 日常任务模板（每天自动导入）
└── todos/
    ├── 2026-06-10.json   # 当日待办
    ├── 2026-06-09.json   # 历史待办
    └── ...
```

## 🛠️ 技术栈 (Technology Stack)

| 层 | 技术 |
| --- | --- |
| **前端** | Vue 3 (CDN，无需构建) |
| **后端** | Express (Node.js 本地服务器) |
| **数据** | 模块化本地 JSON 文件 (`data/` 目录) |
| **架构** | 多页应用 (MPA) + REST API，前后端分离 |
