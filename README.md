# 🌱 Self-Management System (RPG 版自我管理系统)1

这是一个将"个人管理"游戏化的全栈 Web 应用。通过将任务管理、奖励机制与 RPG 属性树相结合，提升个人成就感。

## 🌟 核心创意

- **智能待办 (Smart Todo)**：
  - 支持 0-10 优先级（含小数），自动降序排列，双击编辑文字
  - **按日期分文件存储**，每天独立管理
  - **日常任务模板**，设置后每天自动导入
  - **日期选择器**，可查看任意日期的待办
  - **一键继承**，将上一天未完成的待办加入今天
  - **打勾划线保留**，完成的任务保留可见

- **RPG 属性成长 (RPG Attributes)**：完成待办赚取经验值 → 升级 → 获得属性点 → 加点（力量/智力/耐力/精神）
- **幸运大转盘 (Reward Turntable)**：完成待办获得抽奖次数，转盘赢取 XP 或属性点奖励
- **数据统计 (Data Stats)**：🚧 开发中
- **模块化 JSON 持久化**：数据按模块分目录存储，换设备拷贝 `data/` 即可迁移

### 📂 数据目录结构

```text
data/
├── global.json           # RPG + 转盘全局数据（等级、属性、抽奖次数等）
├── dailies.json          # 日常任务模板（每天自动导入）
└── todos/
    ├── 2026-06-10.json   # 当日待办
    ├── 2026-06-09.json   # 历史待办
    └── ...
```

## 🛠️ 技术栈 (Technology Stack)

| 层 | 技术 |
| --- | --- |
| **前端** | Vue 3 (CDN，无需构建) |
| **后端** | Express (Node.js 本地服务器) |
| **数据** | 模块化本地 JSON 文件 (`data/` 目录) |
| **架构** | 多页应用 (MPA) + REST API，前后端分离 |
